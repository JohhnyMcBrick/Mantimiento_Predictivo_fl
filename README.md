# Mantenimiento Predictivo en Flotas Vehiculares

## Descripción del problema

Las empresas que operan flotas de vehículos enfrentan altos costos 
derivados de mantenimientos correctivos, es decir, intervenciones que 
ocurren después de que el vehículo ya ha fallado. La ausencia de un 
sistema de alerta temprana genera tiempos muertos no planificados, 
pérdidas económicas y riesgos operativos que afectan directamente la 
productividad. Con el uso de datos telemáticos provenientes de sensores 
instalados en los vehículos, es posible identificar patrones que 
anticipen fallos antes de que estos ocurran.

## Pregunta de investigación

¿Qué variables de los sensores telemáticos de una flota vehicular 
permiten predecir la necesidad de mantenimiento antes de que ocurra 
una falla?

## Métricas de éxito

- Porcentaje de valores nulos por columna inferior al 5%
- Identificación de al menos 3 variables con correlación significativa 
  respecto a la variable Machine failure
- Distribución documentada de la variable objetivo Machine failure, 
  incluyendo el porcentaje de registros por clase
